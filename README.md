# Java String Fundamentals

A personal project designed to practice and demonstrate how **Strings** work in Java. This repository serves as a foundational reference showcasing four fundamental programming concepts.

## Core Concepts Demonstrated

*   **Creation:** Visualizes how to declare and initialize text variables using standard double quotes.
*   **Flexibility:** Proves that strings can securely hold any character type, including lowercase letters, numbers, and symbols.
*   **Concatenation (Joining):** Demonstrates two distinct ways to glue text together: using the standard `+` operator and the `+=` shortcut.
*   **Type Mixing:** Shows Java's automatic type conversion when combining text with numeric types (like `int`).

## Getting Started

### Prerequisites
*   Java Development Kit (JDK) 8 or higher
*   Any text editor or IDE (Eclipse, IntelliJ IDEA, VS Code)

### Running the Program
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory and compile the file:
   ```bash
   javac Main.java
   ```
3. Run the application:
   ```bash
   java Main
   ```
